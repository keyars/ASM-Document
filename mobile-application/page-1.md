# 📚 Audit History

The **Audit History** section allows users to monitor all previously conducted audits by date. It provides a visual log of completed and in-progress audits and enables users to resume or review results with ease.

**📅 Calendar Navigation**

* Switch between **Week** and **Month** views.
* Tap a specific date to view audits performed on that day.

**📝 Audit Log Details**

* **Audit Timeframe**: Displays exact start and end times.
* **Audit Location**: Name of the location audited.
* **Status**: Shows whether the audit is **Completed** or still in progress.
* **Status Summary**:
  * Total Available
  * Not Available
  * Disposed
  * Maintenance

**User Action:**

* Tap an audit record to view detailed status.
* If the audit is incomplete, the user can resume the scanning process to complete it.
* Deletion option is available for erroneous or test entries (with proper access).

This section provides traceability and transparency for audit operations across any time frame.
